# DarkAuraX Bot (Simple Version)

Easy-to-upload version for iPhone users.

## How to Deploy on Render

1. Upload these 3 files only:
   - `index.js`
   - `package.json`
   - `README.md`

2. On Render:
   - Build Command: `npm install`
   - Start Command: `npm start`

3. Add Environment Variable:
   - Key: `OWNER_NUMBER`
   - Value: Your number (example: 2348012345678)

4. Deploy and check Logs for the Pairing Code.
